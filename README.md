# 🌄 Modern Scenery Image Slider

A sleek, responsive, and modern image slider built with pure **HTML5**, **CSS3**, and vanilla **JavaScript**.

---

## ✨ Features

- **Modern Glassmorphic UI**: Semi-transparent frosted glass navigation buttons and sleek gradient overlays.
- **Cinematic Transitions**: Smooth fade and subtle zoom transitions on active slides.
- **Auto-Play with Pause-on-Hover**: Automatically rotates slides every 4 seconds and pauses when the user hovers over the slider.
- **Interactive Indicators**: Clickable pill-shaped dots that expand to highlight the active slide.
- **Fully Responsive**: Adapts seamlessly to mobile screens, tablets, and desktops.
- **Clean & Standard Code**: Lightweight and easy to customize without complex dependencies.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/slider.git
   ```
2. Navigate to the project directory:
   ```bash
   cd slider
   ```
3. Open `index.html` in your web browser (or use the VS Code Live Server extension).
